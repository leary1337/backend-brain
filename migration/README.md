# Поэтапный перенос из vault

Источники остаются в [исходном репозитории vault](https://github.com/leary1337/vault). Мы переносим проверенный смысл и полезные иллюстрации по одной теме, сохраняя происхождение материала.

## Две исходные редакции

- [12 августа 2024 года, cc2e017](https://github.com/leary1337/vault/tree/cc2e017) — личные тематические конспекты до переработок.
- [26 октября 2026 года, 8c3e245](https://github.com/leary1337/vault/tree/8c3e245) — текущая на момент начала переноса редакция Go backend.

Полные хеши и пути Markdown-файлов записаны в [реестре](source-inventory.csv). Он содержит также навигационные страницы и шаблоны: это список кандидатов для рассмотрения, а не число обязательных будущих статей. Файлы, не являющиеся Markdown, в реестр не включены; вложения проверяются вместе со статьями.

## Решения в реестре

`pending` — не разбирали; `migrated` — перенесли после проверки; `merged` — объединили с другой темой; `skipped` — решили не переносить, причина обязательна. `stage` — предварительная область, а не обещание порядка переноса. `target` и `decision` заполняем по результату совместной работы.

Для локального просмотра исторического файла:

```powershell
git -C D:\vault show 'cc2e017:Programming/Go/Структуры данных/slice.md'
```

Первой общей статьи об устройстве компьютера в старой структуре не было: она подготовлена заново. Смежные материалы Linux и runtime остаются `pending` до разбора соответствующих тем. Старые заметки не объявлены перенесёнными автоматически.
