# Работа с личной базой

- Владелец — Go backend-разработчик. Пиши по-русски, ясно и без ритуальных вводных.
- Следуй `navigation/roadmap.md`; это рекомендованный порядок зависимостей, а не запрет на вопросы из других областей.
- Текущий шаг и очередь хранятся в `navigation/progress.md`. По умолчанию работай только над текущей темой. Не заполняй базу массово без прямой просьбы пользователя.
- Не отмечай тему пройденной, а статью `ready`, пока пользователь явно не подтвердил результат разбора. `verified` отражает проверку источников, а не понимание пользователя; `reviewed` заполняется после совместного разбора.
- Не выдумывай личный опыт, мнение и ответы владельца. Предложенное объяснение помечай черновиком; личные выводы фиксируй из его слов.
- Перед переносом сравни старую редакцию от 12.08.2024 и текущую редакцию vault, когда для темы доступны обе. Сохрани полезные схемы, примеры и авторские формулировки; исправления обоснуй первичными источниками.
- Публичные гарантии, детали реализации и результаты эксперимента обозначай отдельно. Для изменяемых утверждений указывай версию и проверяй первичные источники. Не объявляй запущенным пример, который не запускался.
- Одна статья отвечает на самостоятельный вопрос. Структура из `templates/` — ориентир, ненужные разделы удаляются.
- Обычные относительные Markdown-ссылки; понятные русские заголовки; пути файлов в lowercase-kebab-case. Вложения локальные, с alt-текстом. Для заимствований сохраняй источник и условия использования; чужие изображения автоматически не копируй.
- Отдельная тема может появиться раньше очереди по реальному вопросу, но это не закрывает её предпосылки автоматически.
- После обсуждения обнови текущую статью, прогресс и затронутые строки `migration/source-inventory.csv`. Несколько исходников могут объединяться, один — разделяться; отмечай решение явно.
- Старый vault — источник для чтения; не изменяй и не удаляй его в процессе переноса.
- Репозиторий публичный. Входящие и настройки рабочего пространства исключены из Git; не добавляй их принудительно. Публикуй только явно подготовленные технические материалы.
- Проверка локальных ссылок: `python scripts/check_links.py`. Она проверяет существование файлов, но не истинность содержания, якоря и понимание читателя.
