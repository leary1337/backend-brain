## Ежедневная работа

Открыть эту папку как хранилище Obsidian. `Ctrl+O` — найти заметку по названию, `Ctrl+Shift+F` — искать по содержанию. Новую необработанную мысль можно сразу записать во «Входящие». Для новой статьи доступны [шаблон темы](templates/topic.md) и [шаблон практического разбора](templates/case.md).

Файлы — обычный Markdown, картинки хранятся в `assets/`, схемы можно редактировать как SVG или Mermaid. История изменений хранится в Git. Obsidian Sync и автоматическая отправка изменений не настроены: сохранение файла локально и отправка коммита на GitHub — отдельные действия.
