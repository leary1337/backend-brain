# Входящие

Сюда можно быстро записать мысль, вопрос, кусок кода или наблюдение. Название и оформление свободные. Новые заметки Obsidian по умолчанию создаются здесь.

Файлы этой папки, кроме данного README, исключены из публичного Git. Это локальные записи: их резервное копирование отдельно пока не настроено. Изображения по умолчанию сохраняются в общий `assets/` и не исключены автоматически: перед публикацией проверять состав коммита.

При разборе переносим подготовленные технические выводы в подходящую статью и добавляем связи. Черновик можно сохранить локально.
